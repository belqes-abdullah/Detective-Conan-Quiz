# Detective Conan Quiz 🕵️‍♂️

A clean and interactive single-page web application featuring a Detective Conan trivia quiz, built to practice core frontend development skills.

## 📌 Features
* Interactive single-page quiz interface.
* Smart answer validation accepting multiple valid spellings and formats.
* Custom visual theme inspired by the Detective Conan series.
* Clean and organized project structure.

## 🛠️ Built With
* **HTML5** - Page structure and content.
* **CSS3** - Custom styling and layout.
* **JavaScript** - Interactive quiz logic and validation.

2. **Open** `index.html` in any web browser.
